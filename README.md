# OOP Library 📚

The **Library Management System** is a project developed in **Java** and **PHP** to explore **Object-Oriented Programming (OOP)** concepts through different application environments.

While both implementations are based on the same programming principles, each one has its own purpose and architecture.

## Java Application

The Java application is a **console-based inventory management system**. It allows users to manage products through an interactive terminal menu, focusing on object-oriented design, data organization, and business logic.

### Features

- Register products;
- View inventory;
- Update product information;
- Remove products;
- Interactive console menu;
- Dynamic data management.

## PHP Application

The PHP application is a **web-based library management system**. It allows users to register, view, and manage books through a browser using a responsive interface.

### Features

- Register books;
- View the catalog;
- Display book information;
- Remove books;
- Store data using PHP Sessions;
- Responsive interface with Bootstrap.

## Concepts Applied

Both applications demonstrate the following concepts:

- Object-Oriented Programming (OOP);
- Classes and objects;
- Constructors;
- Encapsulation;
- Code organization;
- Business logic separation.
